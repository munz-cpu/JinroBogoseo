# 사이드뷰 보스전 기본 템플릿

Assets/Scenes/BossFight.unity 씬을 열고 Play를 누르세요.

## 폴더 구성

- Assets/scrips: 게임 스크립트와 이 사용 설명서. 사용자가 만든 폴더 이름을 그대로 유지합니다.
- Assets/Scenes: 보스전 씬.
- Assets/Scenes/보스전자료: 기본 사각형 스프라이트와 한글 표시용 글꼴.

## 씬 구성

보스전 템플릿 아래에 플레이어, 보스, 바닥, 화면 안내, 탄환 보관함(64개), 공격 표시 보관함(16개)이 미리 배치되어 있습니다. Play 전에도 Hierarchy와 Inspector에서 수정할 수 있습니다.

실행 중 오브젝트를 생성하거나 파괴하지 않습니다. 탄환과 공격 표시는 배치된 오브젝트를 활성화해서 재사용합니다. 보관함이 가득 차면 추가 탄환이나 표시는 생략합니다.

## 조작

이동과 공격은 아래 두 키 배치 중 편한 쪽을 사용하세요. 별도 전환 없이 둘 다 사용할 수 있으며 같은 공격의 대기시간을 공유합니다.

| 동작 | 방향키 조작 | WASD 조작 |
| --- | --- | --- |
| 좌우 이동 | ← / → | A / D |
| 2단 점프 | ↑ | W |
| 빠른 낙하 | ↓ | S |
| 근접 공격 (길게 누르기 가능) | Z | 왼쪽 Shift |
| 원거리 공격 (길게 누르기 가능) | X | Enter |
| 부채꼴 탄막 | C | 역슬래시 |
| 재도전 | R | R |

Space로도 점프할 수 있습니다. 두 배치는 같은 플레이어를 조작합니다.
보스는 부채꼴 탄막, 지면 강타, 돌진을 반복하며 체력이 절반 이하가 되면 공격이 빨라집니다.

## 설정 변경

플레이어의 SideViewPlayer에서 이동 속도, 점프, 스킬 키와 재사용 대기시간을 변경합니다. 보스의 ArenaBoss에서 공격 간격과 예고 시간을 조절합니다. FighterHealth의 최대 체력에서 시작 체력을 바꿉니다.

BossArena에는 플레이어, 보스, 카메라, 탄환과 공격 표시 목록이 연결되어 있습니다. ArenaHud에는 씬에 배치된 한국어 텍스트가 연결되어 있습니다. 클래스와 파일 이름은 코드 연결을 위해 영문을 유지하고, Inspector 설정 이름은 한국어로 표시합니다.

R 키는 기존 오브젝트의 위치, 체력, 이동 상태, 재사용 대기시간과 보스 패턴을 초기화합니다.

바닥 윗면은 Y=-4이며, 낮은 발판 2개와 중앙의 높은 발판 1개가 씬에 미리 배치되어 있습니다. 플랫폼 아래에서 뛰어오르면 통과하고 내려올 때 윗면에 착지합니다. 가장자리에서 걸어나가면 떨어지며 공중 점프를 한 번 사용할 수 있습니다. 탄환은 발판을 통과합니다.

플랫폼 위치와 크기는 Hierarchy의 플랫폼/발판에서 변경할 수 있습니다. 발판을 추가하면 ArenaPlatform을 붙이고 BossArena의 착지 가능한 발판 목록에도 연결하세요. 바닥을 이동하면 보스 돌진과 지면 강타 높이도 바닥 윗면을 기준으로 계산됩니다. 시작 위치는 씬에서 직접 맞추세요. 저장, 게임패드, 오디오와 애니메이션은 포함하지 않습니다.

플레이어와 보스 체력은 화면 안내 아래에 미리 배치한 UI Slider 체력바로 표시됩니다. 조작용 손잡이는 없으며 마우스로 체력을 바꿀 수 없습니다. ArenaHud에 각 체력바가 연결되어 피격 및 재도전 시 자동 갱신됩니다.

플랫폼 위에서 아래(S 또는 ↓)를 누른 채 점프(W·↑·Space)하면 현재 발판을 통과해 내려갑니다. 바닥은 통과하지 않으며 아래쪽 발판에는 정상 착지합니다. 내려간 뒤 공중 점프는 한 번 사용할 수 있습니다.
