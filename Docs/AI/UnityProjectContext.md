# Unity 프로젝트 참고사항

2026-11-01 갱신. Unity 6000.6.3f1, URP 17.6, Input System 1.20을 사용합니다. 활성 입력 설정은 Input System입니다. 네트워크와 저장 기능은 없습니다.

## 구성

- Assets/scrips: 사용자가 만든 스크립트 폴더. 보스전 스크립트 7개와 한국어 사용 설명서를 보관합니다.
- Assets/Scenes/BossFight.unity: 빌드 설정에 등록된 보스전 씬.
- Assets/Scenes/보스전자료: 공용 사각형 스프라이트와 한글 글꼴.
- Assets/Settings: 기존 프로젝트 설정과 입력 액션. 변경하지 않습니다.

씬의 보스전 템플릿 아래에 플레이어, 보스, 바닥, 화면 안내, 탄환 64개와 공격 표시 16개가 미리 배치되어 있습니다. BossArena는 Inspector 참조로 이들을 연결합니다. 실행 중 생성·파괴하지 않으며 재도전 시 기존 오브젝트의 상태만 초기화합니다.

게임 스크립트는 기본 Assembly-CSharp와 BossTemplate 네임스페이스를 사용합니다. 클래스·파일·직렬화 필드 식별자는 참조 유지를 위해 영문을 유지합니다. 게임 문구, Hierarchy 이름, Inspector 표시 이름과 설명서는 한국어입니다.

SideViewPlayer에서 이동·키·대기시간을, ArenaBoss에서 공격 시간을, FighterHealth에서 최대 체력을 조절합니다. ArenaHud는 미리 배치한 uGUI Text를 갱신합니다.

이동은 평평한 경기장을 위한 좌표 제한 방식이며 탄환은 이동 구간의 거리로 피격을 판정합니다. 일반적인 플랫폼 지형 충돌 시스템은 아닙니다. Unity 컴파일과 Play 화면을 확인하며 플랫폼 빌드는 검증하지 않았습니다.

조작 배치는 방향키 + Z/X/C 또는 WASD + 왼쪽 Shift/Enter/역슬래시입니다. 근접 공격, 원거리 공격, 탄막 3개를 두 배치가 공유하며 재사용 대기시간도 공유합니다. Shift 대시, Enter 빔, 역슬래시 회복의 이전 개별 배정은 제거했습니다.

2026-11-02: 바닥 윗면을 Y=-4로 내리고 미리 배치한 단방향 플랫폼 3개를 추가했습니다. ArenaPlatform의 SpriteRenderer 경계로 낙하 구간을 검사하고 가장 높은 윗면에 착지합니다. BossArena가 바닥과 플랫폼 배열을 직렬화 참조하며 보스 패턴도 바닥 높이를 사용합니다. 착지, 상승 통과, 하부 통과, 외부 영역, 고속 낙하, 최상단 선택, 바닥 착지, 가장자리 이탈 8개 검증을 통과했습니다.

2026-11-02: 아래+점프로 현재 플랫폼에서 내려가는 동작을 추가했습니다. SideViewPlayer가 서 있는 플랫폼과 일시적으로 무시할 플랫폼을 추적합니다. 발이 윗면 아래로 내려가면 무시 상태를 해제하고 재도전 시에도 초기화합니다. BossArena는 바닥 제외 단일 플랫폼만 착지 검사에서 건너뜁니다. 이동 로직은 입력에서 분리한 Move 메서드로 실행합니다. 내려가기·일반 점프·바닥 보호·공중 점프·아래쪽 바닥 착지 등 6개 검증을 통과했습니다.
